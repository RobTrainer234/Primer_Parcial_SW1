# Despliegue AWS

Esta carpeta documentará la versión desplegada del proyecto.

## Estrategia mínima recomendada

- Frontend CASE: S3 + CloudFront o EC2 con Nginx.
- Backend CASE: EC2.
- Base de datos: RDS PostgreSQL o PostgreSQL en EC2 para una demo simple.
- Artefactos generados: almacenamiento local inicial o S3 si el tiempo alcanza.

## Evidencias requeridas

- URL pública del frontend.
- Endpoint de salud del backend.
- Captura de base de datos conectada.
- Captura de generación o flujo principal funcionando.
