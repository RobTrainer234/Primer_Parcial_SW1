# Código fuente del frontend CASE

Organización propuesta:

```text
nucleo/           Configuración, cliente API e interceptores.
compartido/       Componentes y modelos reutilizables.
funcionalidades/  Proyectos, editor de modelo, validación y generación.
layout/           Estructura visual general.
```

Los nombres internos del proyecto se mantienen en español para facilitar la defensa.
