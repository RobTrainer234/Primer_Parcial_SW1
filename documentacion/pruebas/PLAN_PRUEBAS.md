# Plan de pruebas

## Simulacros obligatorios

### Clínica

Entidades: Paciente, Médico, Consulta, Especialidad.

### Biblioteca

Entidades: Libro, Autor, Usuario, Préstamo.

### Ventas

Entidades: Cliente, Producto, Venta, DetalleVenta.

## Pruebas mínimas por simulacro

- Crear proyecto.
- Crear modelo.
- Crear entidades.
- Crear atributos y claves primarias.
- Crear relaciones.
- Guardar modelo.
- Recuperar modelo.
- Validar modelo.
- Generar backend.
- Descargar ZIP.
- Compilar backend generado.
- Ejecutar backend generado.
- Abrir Swagger.
- Crear, listar, editar y eliminar registros.
- Consumir desde Flutter.
- Probar asistente local sin Internet.

## Evidencias

Cada prueba debe dejar capturas o registros en `evidencias/`.
