# Documentación del proyecto

La documentación se organiza según la guía académica del proyecto.

```text
perfil/           Introducción, problema, objetivos, alcance y justificación.
fundamentacion/   CASE, PUDS, UML, arquitectura, Spring Boot, IA y calidad.
requisitos/       Actores, casos de uso, requisitos funcionales y no funcionales.
analisis/         Modelo de contexto, paquetes, datos y lógica.
diseno/           Arquitectura lógica, física, motor de generación y UI.
implementacion/   Tecnologías, configuración, decisiones y módulos construidos.
pruebas/          Plan, casos, resultados, errores y re-pruebas.
anexos/           Repositorio, capturas, API, manuales y despliegues.
```

Fuente principal: `GUIA DEL PROYECTO.txt`.
